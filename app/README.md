# SLAD 반응재 배치 방식 비교 시뮬레이터 (v4.3)

농경지 불포화대에서 질산염이 지하수로 내려가는 것을 막는 **황 기반 독립영양 탈질(SLAD, 황:CaCO₃ = 3:1 v/v)** 반응재를,
흙수조 안에 어떤 구조로, 어떻게 넣는지에 따라 비교하는 3D 반응성 지하수 시뮬레이터입니다.
비교군(3MF + 작용 설명 + 설치 단계 표 + 시약 형태)은 사용자가 넣습니다. 코드에 고정된 비교군은 없습니다.

> **결과 해석 원칙** — 실험 데이터로 보정·검증하기 전의 정량값은 모두 **"모델 가정에 따른 비교 결과"** 입니다.
> 신뢰성은 세 가지로 나눠 봅니다: ① 자체 점검(방정식을 맞게 푸는가) ② 실험 보정·검증(실험을 재현하는가) ③ 불확실성(가정 값이 바뀌면 얼마나 흔들리는가).
> 질량수지가 맞는다는 것은 물리적으로 옳다는 증거가 아닙니다.

## 실행

`run_app.bat` 더블클릭 → 패키지 확인 → 엔진 확인(`engine_check.json` 기록) → 브라우저에서 앱이 열립니다(Windows 11, Python 3.12.10에서 확인).

```
python -m pip install -r requirements.txt
python -m streamlit run app.py              # 화면 코드는 app_ui.py
python engine_check.py                     # PHREEQC·OGS·PFLOTRAN 설치 상태 기록
python selftest/selfcheck.py               # 자체 점검(해석해·보존 시험)
python selftest/known_issues.py v3         # 알려진 문제 재현·회귀 시험
```

PHREEQC 라이브러리는 `engine_bin/IPhreeqc-3.7.3.dll`(Windows 64비트)을 함께 넣었으므로 따로 설치하지 않아도 됩니다.
pip 패키지 `phreeqpy`가 있으면 그 안의 라이브러리를 먼저 씁니다. 라이브러리를 찾지 못하면 **내장 화학**으로 계산하고 화면에 그 사실을 표시합니다.

## v4.3 — 주입량의 격자 의존 제거(우물 모델), 공정성 기준 분리, 표본 지표 정정

변경 목록은 `CHANGELOG.md`, 가정·한계는 `limitations.md`. 시험 기준은 구현 전에 `selftest/selfcheck.py`에 적었고 이후 바꾸지 않았습니다
(예외 1건: S5 배치 시간 24 h → 2 h, 설정 오류 수정 — CHANGELOG 기록).

**A. 우물 모델(`well.py`)** — 가는 스크린은 셀 열로 풀지 않고 방사 저항으로 처리합니다. 우물 축이 지나는 셀 4개 수평 면에
(우물 r_w → 충전재 r_pack → 흙 → 이웃 셀 중심) 방사 해와 같은 직렬 저항을 넣습니다. Peaceman 우물 지수는 이 앱 격자에서 r_o(≈0.2·dx)가
충전재 반지름보다 작아 음수가 되므로 그대로 쓰지 못했고, 같은 방사 해를 면 저항으로 구현했습니다(적용 범위: 격자 칸 > 우물 완결부 지름).
체거름 입자(d_p/d50 > 0.154)의 케이크는 셀 공극이 아니라 충전재 고리 공극+스크린 내부 용량(3.98 cm³)에 쌓이고, 차면 우물이 막힙니다.
- **200 µm(체거름)**: 22·33·44 격자에서 전달량·황 전달량이 같습니다(T-grid 표). 통과.
- **10 µm(흙 공극 통과)**: 전달량은 모두 계획량 2.84 L이지만 22→33 격자에서 압력 한도(300 kPa)에 걸린 주입 시간이 28 → 55분으로 2배 차이가 납니다.
  원인: 필터 케이크가 자라는 구간(약 1/λ)이 격자 칸보다 얇아 셀 평균 저항이 격자 크기에 따라 달라집니다(국소 세분화 A2는 미구현).
  → T-grid(10 µm) 기준(차이 ≤ 10 %) **미통과**로 기록합니다. 44×44×72 10 µm 실행은 33분째에 사용자 요청으로 중단해 결과가 없습니다(표에 '미완료'). 따라서 이 시험은 22·33 격자 두 개만으로 "미통과"를 기록하고 44 격자 확인은 하지 못했습니다.
- **A5 구멍 판·케이슨 격자 안정(CAIS-grid)**: 통과 물 0.103/0.057/0.103 L(차 80 %), 장치 제거율 2.10/2.66/2.56 %(차 27 %) → **미통과**.
  원인: 케이슨 반응재가 지름 12 cm·두께 수 cm로 22~44 격자의 몇 칸밖에 안 됩니다. 한계에 기록.

**B. 공정성 기준(격자와 분리)** — 목표 황 질량 입력(`target_S_g`), 스크린 길이는 현장 규모 기하 상사(2 gpm/ft는 현장 참고값),
케이슨 두께 = max(체류시간 계산값, 프린터 최소 두께). 도메인 η와 포획 기반 장치 제거율을 항상 함께 보고합니다.
예시 케이슨 목표 황 = 영구 주입공(10 µm 입자) 전달 **851 g S**, 층 최소 두께 4 cm(입력·가정) → 지름 17 cm, 포획 9.1 %, 챔버 가로 7.5칸. (200 µm의 6.18 g S는 지름 4 cm가 되어 격자에 안 잡혀 기본값에서 뺌.)

## v4.2 — 규칙 R1~R9, 실험 형상(Part 1·2), 구멍 판(Part 3), 지표 정정(Part 5)

> v4.3에서 케이슨 치수·목표 황 질량·스크린 길이 계산이 바뀌었습니다(위 v4.3 절이 우선). 아래는 v4.2 시점 기록입니다.

변경 목록은 `CHANGELOG.md`, 모델 가정·한계는 `limitations.md`에 있습니다(화면에는 한계 문구를 넣지 않음).

**깊이 구간(두 비교군 공통)**: 지표 ~ 지하수면 − 여유 거리. 기본 조건(사양토, 바닥 경계 '지하수 수위', H_soil 0.70 m)에서
지하수면 0.70 m(바닥 경계에서 계산해 기록), 여유 1/α = 0.133 m(가정) → **0 ~ 0.567 m**. 반응재·주입 개구부가 이보다 깊으면 오류로 멈춥니다.

**영구 주입공 스크린 길이**: L_s = 설계 주입률 / 2 gpm/ft(EPA 2013 p.44) = 0.2 L/min ÷ 24.8 L/min/m = **8.1 mm**.
가용 구간 0.567 m의 0.25·0.5·0.75·1.0배 × 1~3구간 표를 ① → 형상·크기 계산기에서 보고 그대로 3MF로 만들 수 있습니다.
기존 예시(스크린 하단 0.541 m)는 깊이 구간 안이라 형태를 유지했습니다.

**케이슨 — 불포화대 적용형(caisson_down)**: 불투수 측벽 + 투수성 상판(유입) + 반응재층 + 투수성 하판(유출), 하향 침투.
Part 2 계산기(모드 A, SF 2, 반응재 포화도 0.5, O₂ = K_O2 가정)로 정한 예시 치수: 지름 **12.4 cm**, 반응재 두께 **4.72 cm**
(체류시간으로 정한 두께 z = V·t·SF ≈ 6 mm보다 구조 최소(격자 2칸)가 커서 구조 최소가 결정), 상판 깊이 4.7 cm, 바닥 깊이 10.0 cm,
반응재 질량 = 영구 주입공이 실제로 전달한 황 530 g에 맞춤(항목 6). 포획 분율 **4.8 %**(투영 면적), 반응 챔버 가로 5.4칸(K4 통과).
구멍 판: 지름 2 mm, 개구율 20 %, 두께 3 mm, 채움 반응재/흙(가정, 역할표에서 수정·⑧ 스윕). 근거는 `samples/caisson_down.json`.
기존 Monkstown형은 `monkstown_saturated_reference.3mf`(포화대 상향 흐름 참고, 불포화대에서는 반응재를 거의 지나지 않음)로 남겼습니다.

**지표 정정**: 계획·전달 황 질량과 전달률(X2), η의 반응 기여·흐름·저장 기여 분리(X3), 기준 η < 1 %면 R 계산 안 함(X4),
대조군 대비 ΔpH(X5), V_eff 두 정의(X6), 황 사용처(탈질 2.52 g S/g N · 호기성 산화, X7), 초기 η 대조군 분리(X8),
반응 구역 포화도 시계열 평균·최소·최대 저장(X10).

**R4 물 수지 허용 오차**: 뉴턴 수렴 기준 |Δh| < 1e-6 m에서 한 단계 저장량 오차 ≤ tol·ΣC(h)·V → 실행마다 상한을 계산해 기록합니다.

## v4.1 연구 설계 반영 — 독립변수·통제변수·핵심 지표·조건 비교

**연구 목적(그대로 반영):** 기존 지중 수리 조건에서 황 기반 슬러리 장치(영구 주입공, 케이슨형)가 지하수로 들어가는 질산염을 얼마나 제거·차단하는지 평가한다. 지하수 흐름은 개선·최적화 대상이 아니다.

| 구분 | 변수 | 어디서 |
|---|---|---|
| 독립변수 | 황 총 투입량(g), 황 입경(mm)·비표면적(m²/g), 황:물 배합(황 1 g당 물 g), 수분 유지 재료(종류·건조 고형분 w/w), 반응 구역 수분(계산값 또는 지정 포화도), 탈질 수분 함수(NEMIS·사용자 지정·끔) | ① 비교군 → '🧪 황 투입량·입경·슬러리 배합', ② → 수분 조건 |
| 통제변수 | 지하수 유속·수위·하단 조건, 지층(토성·Ks·층), 유입·초기 질산염 농도, 관개량, 온도 | ② 공통 조건(모든 비교군 같음) |
| 결과 | 아래 핵심 지표 11개, 90일·180일 | ④ 결과, ⑧ 조건 비교·최적화 |

**핵심 지표(④ 결과 맨 위 표, 90일·180일·끝 칸):** 1 초기 지하수 NO₃-N · 2 장치 유입부 NO₃-N(반응 구역으로 들어간 물의 유량 가중) · 3 장치 하류 NO₃-N(반응 구역에서 나온 물) 및 흙수조 바닥 유출 · 4 장치 제거율(반응 구역 안 탈질 N ÷ 들어간 N; 농도 기준값도 함께) 및 대조군 대비 지하수 유입 감소율 · 5 시간에 따른 농도(그림) · 6 황 초기 투입량 · 7 황 소비량(탈질 + 공기 산화) · 8 잔여 황 · 9 반응 구역 포화도·θ 변화 · 10 수분 조건별 효율(⑧에서 포화도 스윕) · 11 황 투입량·소비량 대비 제거 N(g N/kg S). 우회 비율 = 1 − (반응재 통과 유량 ÷ 반응재가 없을 때 같은 자리 유량), 같은 흙·경계 조건의 정상해로 계산(임의 설정 아님).

**⑧ 조건 비교·최적화:** 황 투입량·반응 구역 포화도·입경·황:물 배합·수분 유지 재료 비율 중 하나를 여러 값으로 바꿔 두 장치를 같은 환경에서 계산(대조군은 한 번). 기간 90/180일. 그래프 3개(제거율, g N/kg S, 황 소비), 표, 다목적 점수 = w₁·제거율/최대 + w₂·(g N/kg S)/최대 − w₃·황 투입량/최대(가중치 조절), 파레토 표시. 제거율만 최대화하지 않음.

**수분 조건 구현:**
- 탈질 수분 함수 f(s) = ((s − s_t)/(1 − s_t))^w. 기본(NEMIS, Hénault & Germon 2000: s_t 0.62, w 1.74)은 **토양 종속영양 탈질 문헌값을 빌린 기본 시나리오**이며 불포화 황 충전층·황 슬러리에서 검증된 임계값이 아니다. 문턱·지수를 사용자 값으로 바꿀 수 있고, 끌 수 있다(낙관적 상한). ②에 함수 그림 표시.
- 반응 구역 수분: '계산값' = Richards(흙·충전재·수분 유지 재료의 수분특성으로 계산), '지정' = 반응 구역 포화도를 조작변수로 지정해 반응(수분 함수·호기성 황 산화)에 씀. 물 흐름·이송·공기 확산은 계산값 그대로(통제변수). 기상이 이어진 셀에서는 용존 O₂ 억제를 걸지 않는다(무산소 미소 부위는 수분 함수가 대표).
- 결과 표에 체적함수비 θ와 포화도 s를 따로 표시.

**황 투입량·입경:** 투입량을 정하면 슬러리 비교군은 '시약 주입' 행 부피를 배합에서 계산해 맞추고(행 비율 유지), 사전 배치 비교군은 충전재의 황 양을 맞춘다(남는 부피는 공극, 투수계수는 Kozeny–Carman). 반응 속도 = k½a × 비표면적(입경 또는 측정 비표면적), 입자가 녹으면 표면 ∝ 부피^(2/3). 황 소비 = 탈질 + 공기 산화, 투입량에 비례해 제거가 늘지 않는다(물질전달: 통과 유량·수분·표면적이 제한).

**황 슬러리 배합·수분 유지 재료(문헌 근거와 한계):**

| 재료 | 넣은 효과 | 근거 | 가정·불확실 |
|---|---|---|---|
| 물만 늘림 | 주입 부피·처음 젖는 정도 증가, 이후 흙 수분특성대로 빠짐 | 물리(질량 보존) | — |
| 벤토나이트(0–9 % w/w) | 반응 구역 Ks: 0 % 3.60e-5, 3 % ≈1e-7, 9 % 4.13e-9 cm/s를 로그 보간 | Chalermyanont & Arrykul (2005) 다짐 모래-벤토나이트 | 보수성(수분특성)은 점토 쪽 보간(가정), 팽윤 없음, 다짐 시료 값 |
| 바이오차 | 공극률 +8.4 %, Ks +25.2 %, 유효수분 +15.1 %(5 % w/w 기준 선형 환산) | Omondi et al. (2016) 메타분석 평균 | 투입률 환산(가정), 재료·입경별 차이 무시 |
| 고흡수성 수지(SAP, ≤0.7 % w/w) | 건조 중 수분 +88 %를 유효수분 증가로, 용적밀도 −12.5 % | Aslan & Canbolat (2025) 사양토 시험 | Ks 배율 1(크기 미상), 팽윤 부피 없음 |
| 사용자 정의 | Ks 배율·공극률·α·n 직접 입력 | 실험값 | — |

황 입자의 소수성(물에 잘 젖지 않음)과 분산제, 슬러리의 유변학(점도)은 정량 문헌을 찾지 못해 계산하지 않는다. **불포화 황 기반 탈질에서 수분 함량의 영향을 직접 잰 논문도 찾지 못했다** — 수분 함수와 수분 유지 재료 효과는 이 연구의 흙수조 실험으로 보정해야 할 1순위 불확실성이다(⑥ 실험 보정).

**시험 예(⑧, 가벼움 격자, 90일, 반응 구역 포화도 지정 0.85, 2코어 서버 11분):** 황 투입량 200 g → 800 g. 영구 주입공은 800 g을 지정해도 **530 g만 들어감**(개구부 공극 한도, 결과 경고) — 장치 구조가 담을 수 있는 양의 한계. 장치 제거율(반응 구역에 들어간 N 중 탈질) 91–94 %, 지하수 유입 감소율 2.1→2.5 %(대조군 대비), 90일 황 소비 20–24 g(대부분 공기 산화). 케이슨형은 바닥이 막혀 통과 유량이 거의 없어(우회 100 %) 투입량을 늘려도 지하수 유입 감소율 4.4 % 그대로. 즉 투입량보다 '물이 반응 구역을 지나는 양'이 성능을 정한다(모델 가정 하).

**이 결과가 말하는 것(모델 가정 하의 결과):**
1. 두 예시 모두 반응 구역의 포화도가 0.16~0.22로 낮다(굵은 개구부·충전재는 물이 빠짐). 문헌 수분 함수를 적용하면 이 구역에서는 탈질이 거의 없고, 슬러리 황은 공기로 산화되어(90일에 약 4%) 황산염만 늘어난다.
2. 수분 함수를 꺼도(낙관적 상한) 지하수 피해 감소는 3~4%에 그친다. 대조군 질산염 3.3 g 중 반응재를 지나는 물에 실린 양이 적기 때문이다: **반응 속도보다 '물이 반응재를 지나는가'(통과 유량)가 성능을 정한다.** 케이슨은 바닥이 막혀 통과 유량이 0(⑤ 탭 진단), 주입 슬러리는 개구부에 케이크로 남아 흙으로 퍼지지 않았다.
3. 따라서 설계 비교에서 먼저 볼 것은 (a) 반응재를 지나는 물의 비율, (b) 반응 구역을 젖은 상태로 유지하는 방법(지하수면 가까이, 보수성 재료)이다.

**아직 못 한 것(정직하게):** 불포화 황 충전층에서 탈질을 직접 잰 논문을 찾지 못해 수분 함수는 토양 탈질 식을 빌린 것이다. 아질산 중간체, 흙덩이 안 무산소 미소 부위의 직접 계산, 이 흙수조·이 황 제품으로의 보정은 없다. 흙수조 실험 자료를 ⑥ 탭 '실험 보정'에 넣으면 속도상수·수분 문턱을 맞출 수 있다.

흐름·이송은 v2 엔진(3D Richards 유한체적 + TVD 이송)을 유지했습니다. 이 연구에 꼭 필요한 기능(입자 포획·막힘 되먹임, 설치 단계마다 3MF 복셀 속성 갱신, 면 장벽)이 OGS/PFLOTRAN에는 없어 단계마다 메시·속성을 다시 만들어야 하고, 무엇보다 이 환경에서 두 프로그램을 설치·실행해 확인할 수 없었기 때문입니다.

**버전·위치·라이선스**
- IPhreeqc 3.7.3-15968: `engine_bin/IPhreeqc-3.7.3.dll`(Windows x64, phreeqpy 저장소에서 가져온 원본). PHREEQC/IPhreeqc는 미국 지질조사국(USGS) 저작물로 퍼블릭 도메인입니다. phreeqpy는 BSD 라이선스(Copyright (c) 2011 Mike Müller and contributors)이며, 이 앱은 phreeqpy 코드는 쓰지 않고 그 안의 라이브러리 파일만 씁니다.
- `engine_data/phreeqc.dat`: IPhreeqc 저장소 태그 v3.7.4의 데이터베이스(원본 그대로).
- 받은 코드(라이브러리·DB)는 수정하지 않았습니다. 필요한 정의는 `phreeqc_engine.py`가 PHREEQC 입력 문자열로 덧붙입니다.

### 연결 방식
1. 흐름(Richards) → 면 유량·θ → 이송(TVD): 파이썬 엔진.
2. 반응: 반응재 셀(황·석회석·석고가 있는 셀)을 모아 PHREEQC 회분 계산(`RUN_CELLS`)을 `chem_dt_h`(기본 2시간)마다 호출하고, 반응 뒤 농도·고체량을 엔진 배열에 되돌려 씁니다.
3. 엔진에 없는 기능(입자 포획·필터 케이크, 공극 막힘 → Kozeny–Carman K, 설치 이벤트별 속성 갱신)은 파이썬이 처리하고, 바뀐 K·공극률을 다음 흐름 단계에 넣습니다.
4. 초기 O₂ 단계·액체 공여체 반응은 내장 코드로 먼저 계산(연산자 분할)한 뒤 PHREEQC를 부릅니다.

### PHREEQC에 덧붙인 정의 (`phreeqc_engine.EXTRA_DEFS`)
- `Nit`: 질산염을 산화환원과 분리한 보존 성분(phreeqc.dat의 N(5)/N(0) 평형이 탈질을 '즉시 평형'으로 처리하는 것을 막음).
- `RATES SLAD`: 반-차수 속도식 × 황 잔량 × pH 함수 × 온도 보정. 반응식 `HNit −1, H2SO4 +1.10`(전하 중성) → 산 생성 1.20 eq/mol NO₃. 내장 화학의 1.28은 암모늄 흡수를 포함한 Batchelor & Lawrence 값이라 두 엔진의 알칼리도 소비가 약 6% 다릅니다(문서화).
- `RATES Calcite_c`: PWP 속도식. phreeqc.dat Calcite 속도식과 같고, k3가 25°C에서 끊기지 않게 고친 판(A5).
- `EQUILIBRIUM_PHASES`: CO₂(g)(셀별 pCO₂), Gypsum(평형), 평형 모드면 Calcite.
- 작업 중 정의 블록이 기본 회분 반응을 한 번 더 일으키는 **이중 반응** 버그를 발견해 `USE solution none`으로 막았습니다(수정 전 황 수지 1e−3, 수정 후 ~1e−8).

- 얇은 주입 개구부가 격자마다 다르게 잡힌다: 개구부 셀 수 ×1 = 56, ×1.5 = 21, ×2 = 108. ×1.5에서는 개구부 셀 1개가 벽에 완전히 갇혀 있었다(이제 주입에서 빼고 경고). 개구부처럼 얇은 부분의 결과는 격자 선택에 따라 달라질 수 있으니 격자 간격을 개구부 두께보다 작게 잡을 것을 권한다.
- 기본 주입 모델(과도 Richards)의 ×2 주입 사례는 수렴하지 못했다(아래 A의 미완료 설명).

## 시약 형태

| 형태 | 계산 방식 | 지표 3·4·5에서 기대되는 차이 |
|---|---|---|
| (a) 고체 사전 배치 | 반응재 역할 객체 셀에 황·석회석 고체 | r = 객체 범위, K 변화는 반응·생물막만, 재보충은 개구부가 있어야 가능 |
| (b) 고체 카트리지 교체 | '교체 가능' 반응재를 재보충 때 새것으로(φ_ref 초기화) | R이 높고 K가 회복 |
| (c) 입자 슬러리 | 입자 이송·여과 포획, 입경비가 크면 필터 케이크 | r = 포획 거리, 개구부 주변 K 감소 누적 |
| (d) 용존 전자공여체 | 이송 성분 D(지연계수 R), Monod 소비, 사용자 입력 양론 | 고체 없음 → K 감소 작음, 넓게 퍼지고 씻겨 나감 |
| (e) 콜로이드·나노 현탁 | 입자 PC(작은 λ, 순수 황) | 슬러리보다 멀리 감 |

- 액체 시약 물질은 정해지지 않았습니다. 드롭다운(티오황산염, 콜로이드 황, 사용자 정의)에서 고르고, 양론·속도를 넣지 않으면 **계산하지 않고 이유를 안내**합니다.
- 티오황산염 양론(5 S₂O₃²⁻ + 8 NO₃⁻ + H₂O → 10 SO₄²⁻ + 4 N₂ + 2 H⁺)은 문헌 참고값으로 미리 채우지만 **속도 상수는 미정**입니다.
- 같은 황 당량·같은 주입 부피 기준 비교용으로 비교군별 황 당량(mol S)과 주입 부피(L)를 계산합니다(`planned_masses`).

## 알려진 한계 (화면에는 표시하지 않음)

모델 가정·한계 전체는 `limitations.md`와 Excel의 "한계·가정" 시트에 있습니다(화면 정책: 결과 화면에는 한계 문구를 넣지 않음).
격자 해상도 진단(반응 챔버 칸 수, 얇은 구조의 면 장벽 처리)은 실행 로그와 Excel에 기록합니다.

- 실험 보정 전의 모든 값은 모델 가정에 따른 비교 결과입니다. SLAD 속도상수는 이 흙수조·황 제품으로 보정되지 않았습니다.
- 불포화 탈질의 수분 의존(p, K_O2, NEMIS 임계값)은 문헌으로 직접 뒷받침되지 않습니다 — 모드 A·B·C를 나란히 내고 순위 일치 여부를 기록합니다(S16).
- 관 내부 자유수: 관 지름을 주면 Hagen–Poiseuille 등가 K, 그 밖의 관 흐름 조건(Re 점검·Darcy–Weisbach·Manning·노드 연속)은 미구현.
- 할렬 주입은 표현하지 않고, 100 psi를 넘은 주입은 "파쇄 가능, 결과 무효"로 표시합니다.
- 계산 시간은 아래 "v4.2" 절의 측정 표를 보세요.
