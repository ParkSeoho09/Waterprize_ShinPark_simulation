작성일: 2026-10-26 (한국 시간)

대상: 일정 함수율과 주어진 유동장에 대한 3차원 질산염 보존형 수송 엔진.

## 1. 이번 단계의 연구 질문과 범위

**함수율·물 플럭스·분산계수·질산염 유입조건이 주어졌을 때, 질산염의 3차원 농도분포와 깊이별 통과곡선, 하부 유출 질량을 정확하게 계산할 수 있는가?**

Stage 1은 불포화 토양을 단일 연속체로 근사하고, 액상에서 이동하는 질산염을 보존성 용질로 취급한다. 초기 구현에서는 함수율과 물 플럭스가 공간·시간에 대해 일정하다. 초기 농도와 경계 유입은 3차원 분포를 가질 수 있다. 따라서 단순한 1차원 계산의 화면상 확장이 아니라 x·y·z 방향 셀 간 수송을 모두 계산한다.

물의 젖음 전선, 강우에 따른 함수율 변화, 주입에 의한 유동장 변화는 아직 계산하지 않는다. 이 단계의 결과는 **주어진 정상 유동장에서의 수송 예측**이며, 실제 토조에서의 비정상 침투 재현 여부는 이후 수리모델과 실험으로 평가한다.

이번 단계에는 반응·탈질·흡착·침착·주입수·서비스관·배치 최적화·GUI를 넣지 않는다. 수송만 있는 조건에서 질산염 질량 감소를 정화로 해석해서는 안 된다.

## 2. 문헌과 자체 설계의 경계

- **기준 문헌 [S1]**: Filipović, Ondrašek & Filipović (2016), DOI 10.5772/63496. §3.2 식 (13)–(17)의 이류·분산 플럭스와 질량보존, §3.3의 초기·경계조건을 참고한다. 해당 장의 수식 설명과 사례는 1차원이므로 본 프로젝트의 3차원 엔진이 문헌에서 이미 검증되었다고 표현하지 않는다.
- **수치 기반 [S2, S3]**: FiPy의 셀 중심 유한체적법과 시간·대류·확산항을 사용한다. Upwind의 수치분산은 공식 문서에도 명시되어 있으므로 별도 정량 검증 대상으로 둔다.
- **독립 비교 [S4]**: OpenGeoSys의 Unsaturated Mass Transport 예제는 Padilla et al.의 NaCl1·NaCl6 컬럼 사례다. 이는 용질 수송 비교에 유용하지만 질산염 반응이나 3차원 주입 구조의 검증 자료는 아니다.
- **자체 설계**: 아래의 3차원 확장, 경계조건 계약, 진단·저장 규격, 시험 조합과 통과 기준은 이번 프로젝트의 개발 제안이다. 통과 기준은 국제 인증기준이나 문헌의 실측 오차를 뜻하지 않는다.

## 3. 권장 기술 구성과 모듈

Python + NumPy + FiPy + SciPy + Matplotlib + pytest를 기본으로 제안한다. FiPy로 유한체적 이산화와 희소 연립방정식을 구성하고 SciPy 솔버를 사용한다. NumPy는 데이터·진단 계산, Matplotlib는 단면과 BTC 출력, pytest는 자동 검증을 담당한다. PyVista는 계산 결과의 3D 표시용 선택 의존성으로 두며 설치·표시 환경 때문에 수치시험이 막히지 않게 한다.

## 4. 지배방정식·기호·단위

Stage 1에서 풀 방정식은 다음과 같다.

\[
\frac{\partial(\theta C)}{\partial t}
+\nabla\cdot\mathbf J=0,
\qquad
\mathbf J=\mathbf q C-\theta\mathbf D\nabla C.
\]

| 기호 | 의미 | 내부 단위 |
|---|---|---|
| \(C\) | 토양수 부피당 용존 질산염 농도 | kg/m³ of water, 질량 기준 별도 명시 |
| \(\theta\) | 체적함수율(전체 토양 부피 중 물의 비율) | m³/m³ |
| \(n\) | 공극률(전체 토양 부피 중 공극의 비율) | m³/m³ |
| \(\mathbf q\) | Darcy 물 플럭스(전체 단면적당 유량) | m/s |
| \(\mathbf u=\mathbf q/\theta\) | 공극수 평균 이동속도 | m/s |
| \(\mathbf D\) | 수리동역학적 분산계수(기계적 분산·분자확산 포함) | m²/s |
| \(\mathbf J\) | 전체 단면적당 용질 질량 플럭스 | kg/(m²·s) |

**q와 u를 혼용하지 않는다.** FiPy 대류항 계수는 이 보존형 방정식에서는 q, 시간항 계수는 θ, 분산항 계수는 θD다. 질량은 \(M=\sum_i\theta_i C_i V_i\)로 계산한다.

내부 농도는 kg/m³, 화면·CSV 표시 농도는 mg/L로 변환할 수 있다. 1 mg/L = 0.001 kg/m³다. 입력에는 `nitrate_basis: NO3` 또는 `nitrate_basis: NO3-N`을 반드시 넣는다. 하나를 기본값으로 몰래 가정하지 않는다. 모든 질량 출력은 같은 기준을 유지하고 변환 시 사용한 몰질량을 기록한다.

초기 D는 일정한 대각 성분 \(\operatorname{diag}(D_x,D_y,D_z)\), 각 성분은 0 이상으로 제한한다. 일반적인 비대각 분산 텐서는 이번에 검증하지 않는다. 비스듬한 유동에 임의의 대각 D를 주는 시험은 수학적 ADE 검증이며, 이를 실제 토양의 종·횡 분산 법칙으로 간주하지 않는다. 향후 방향이 변하는 주입 유동에서는 전체 텐서를 별도로 구현·검증해야 한다.

## 5. 격자·좌표·유동장 계약

- 직교형 셀 중심 3D 격자를 사용한다. x·y는 수평, z는 **아래쪽이 양수**, 지표 z=0, 하부 z=Lz로 고정한다.
- 공개 배열 순서는 농도 `C[time, z, y, x]`, 함수율 `theta[z, y, x]`다. FiPy의 내부 인덱스와 변환하는 왕복 시험을 둔다.
- 면 플럭스는 각 축의 양의 방향으로 저장한다. `qx[z,y,x_face]`, `qy[z,y_face,x]`, `qz[z_face,y,x]`이며, 면적을 곱하면 m³/s다. 경계 외향 법선 부호는 별도로 적용한다.
- Stage 1 유동 공급자는 일정 θ·q만 구현한다. θ가 일정하고 물 공급원이 없으므로 셀별 물 유량의 순유출 합이 0이어야 한다. 불일치하는 유동장과 경계조합은 입력 단계에서 거부한다.
- 향후 유동 공급자는 시간단계 양 끝의 θ와 동일 시간적분에 일치하는 면 물 플럭스를 제공해야 한다. 그때도 \(\partial\theta/\partial t+\nabla\cdot\mathbf q=S_w\)를 만족해야 한다. 외부 유동장을 셀 중심 속도로만 보간해 사용하는 방식은 허용하지 않는다.

앞서 제안된 60×20×30 cm는 **임시 수치시험 영역**이며 실제 토조 규격으로 확정된 값이 아니다.

| 균일 셀 크기 | x×y×z 셀 수 | 총 셀 수 |
|---|---:|---:|
| 2 cm | 30×10×15 | 4,500 |
| 1 cm | 60×20×30 | 36,000 |
| 0.5 cm | 120×40×60 | 288,000 |

2 cm로 실행을 점검하고, 1 cm와 0.5 cm를 수렴성 후보로 사용한다. 이 중 하나를 미리 정확한 격자라고 지정하지 않는다. 해석해 시험은 별도의 크기·격자를 사용할 수 있다.

## 6. 초기·경계조건

초기농도는 균일값, Gaussian 분포, 사용자 제공 3D 배열을 지원한다. 해석해 비교에서는 셀 중심의 점값 대신 해석해의 **셀 평균**을 초기값과 기준값으로 사용한다.

| 조건 | 수학적 정의(외향 법선 n) | 적용 |
|---|---|---|
| 질량 플럭스 유입 | \(\mathbf J\cdot\mathbf n=q_n C_{in}(t)\), \(q_n<0\) | 기본 관수 질산염 유입. Cauchy/Danckwerts형 |
| 하부 개방 유출 | \((\theta\mathbf D\nabla C)\cdot\mathbf n=0\), \(q_n>0\) | 대류 질량 유출은 유지 |
| 밀폐 벽 | \(q_n=0,\ \mathbf J\cdot\mathbf n=0\) | 옆면·닫힌 영역 시험 |
| 지정 농도 | \(C=C_b(t)\) | 필요한 해석해·전문모델 비교 |

q는 유동 공급자가 지정하고, 위 표는 그 물 흐름에 대응하는 용질 조건이다. 물 경계와 용질 경계를 같은 설정값으로 대체하지 않는다. 실제 유입 패치는 여러 면 셀의 면적을 합산하여 표현하고, 적용된 면적을 기록한다.

지정 농도 조건에서는 분산 유입도 생길 수 있으므로 유입 질량을 Q×C만으로 계산하지 않는다. 지정 플럭스와 지정 농도는 서로 다른 문제다. OpenGeoSys 예제의 상부 지정 농도 조건과 비교할 때에는 우리 모델도 동일하게 맞춘다.

FiPy의 자연 경계가 무유출인 점에 주의하여 하부 개방 유출을 명시적으로 구현한다. 경계 플럭스는 실제 이산식과 일치하게 진단 모듈로 전달한다. 지원하지 않는 역류가 생기면 중단하고 필요한 유입 농도를 요구한다. 역류를 0으로 바꾸지 않는다.

시간에 따른 유입은 일정 공급과 유한 펄스를 지원한다. 펄스가 끝나면 농도가 0인 물이 계속 유입되는 조건인지, 물 자체가 중단되는 조건인지 구분한다. Stage 1의 일정 유동 시나리오에서는 전자를 사용한다.

## 7. 계산 알고리즘

셀 i에 대해 다음 보존식을 사용한다.

\[
\frac{(\theta C)_i^{n+1}-(\theta C)_i^n}{\Delta t}V_i
=-\sum_{f\in i}J_{i,f}^{n+1}A_f.
\]

초기 수치법은 **1차 Upwind 이류 + 직교 격자의 중심차분 분산 + 후진 Euler 시간적분**이다. 내부 공유면의 J를 한 번 계산하고 양쪽 셀에 반대 부호로 적용한다. 일정 θD에서는 정확한 면 계수를 사용한다. 불연속 매질의 조화평균 등은 이후 확장 시 별도 검증한다.

실행 순서:

1. 설정파일을 읽고 단위·질산염 기준·범위·차원·경계 호환성을 검증한다.
2. 격자를 만들고 θ, q, D, 초기 C, 각 경계면을 설정한다.
3. 종료시각·출력시각·유입 펄스 변곡점에 맞춰 시간단계를 자른다.
4. 해당 단계의 계수와 경계조건으로 FiPy 희소 연립방정식 \(A C^{n+1}=b\)를 구성한다.
5. 선형계를 풀고 스케일을 명시한 잔차·반복 수·수렴 상태를 확인한다. 목표 상대 잔차 10⁻¹⁰은 초기 설정 제안이며 솔버 정의와 함께 기록한다.
6. 실제 사용한 면 질량 플럭스로 모든 경계의 단계별 유입·유출량을 계산한다. 후진 Euler와 동일한 시간 구적을 사용한다.
7. 질량수지·음수·NaN·Inf·최댓값을 검사하고 BTC·분포 지표를 누적한다.
8. 정해진 출력시각에 3D 상태를 저장하고 종료 후 표·그림·검증 요약을 생성한다.

솔버 실패나 의미 있는 음수 농도가 발생하면 유효하지 않은 실행으로 표시하고 중단한다. 농도를 잘라서 양수로 만들거나 질량을 다시 맞추는 보정으로 시험을 통과시키지 않는다.

### 수치분산과 시간간격

암시적 계산이 안정적으로 끝난다는 사실과 정확성은 별개다. 각 축의 \(Co_j=|u_j|\Delta t/\Delta x_j\), \(Pe_j=|u_j|\Delta x_j/D_j\)를 기록한다. D=0이면 해당 Pe는 무한대 또는 별도 상태로 표시한다.

초기 정확도 점검에서는 \(\sum_j Co_j\le0.5\)를 시간간격의 보수적 시작값으로 사용한다. 이는 암시적 방법의 안정성 한계나 정확성 보증이 아니며, 최종 Δt는 시간 수렴시험으로 선택한다.

일정 계수 1D 이류의 작은 Δt 한계에서 1차 Upwind의 대표적인 추가 분산 크기는 \(D_{num}\approx |u|\Delta x/2\)다. 격자·시간시험에서 이것이 물리적 D보다 큰지 확인한다. 세분화 후에도 분포 정확도 기준을 못 맞추면 Stage 1을 완료 처리하지 않고, 이 단계 안에서 더 정확한 이류법을 별도 구현·검증한다. 물리적 D를 늘려 시험을 맞추지 않는다.

## 8. 진단량과 출력 규격

### 질량수지

\[
R_M(t)=M_0+M_{in}(t)-M(t)-M_{out}(t),
\qquad M(t)=\sum_i\theta_iC_iV_i.
\]

Min·Mout은 **여섯 경계 전체**에서 실제 이산 질량 플럭스의 음·양 부분을 누적한다. 하부 유출 질량은 별도 열로 제공한다. 초기량+유입량이 양수인 경우 상대오차는 \(|R_M|/(M_0+M_{in})\)로 정의한다. 기준 질량이 0인 구간은 사전에 정한 절대 허용오차로 판정하고 상대오차는 정의 불가로 표시한다.

추가 진단으로 셀별 저장량 변화와 면 플럭스 합의 잔차를 계산하여 전역 오차에서 상쇄되는 국소 오류도 확인한다.

### BTC와 공간분포

- 깊이별 BTC: 해당 층 토양수 부피로 가중한 resident 농도 \(\sum\theta CV/\sum\theta V\). 특정 관측점의 값은 관측점 위치와 샘플링법을 별도 기록한다.
- 하부 유출 BTC: 유출수 유량으로 가중한 농도. 분산 유출이 0인 기본 경계에서는 하부 질량 유출률/물 유출률과 일치한다. 유출 유량이 0이면 농도는 정의 불가로 둔다.
- 플룸 중심·폭: 질산염 질량으로 가중한 중심과 축별 분산을 계산한다. 총 질량이 없으면 지표를 생성하지 않는다.
- 선택 비교량: 누적 유출 질량, 입력 질량의 50%가 유출될 때의 t50. 관측기간 내 50%에 도달하지 못하면 정의 불가로 기록한다.

| 파일 | 내용 |
|---|---|
| `fields.npz` | 시간·좌표, 3D C, θ, 각 면 q, D와 배열 규격 |
| `mass_balance.csv` | 초기·유입·잔류·전체 유출·하부 유출 질량, 잔차, 최소·최대 농도 |
| `breakthrough.csv` | 깊이·관측점 resident BTC와 하부 flux BTC, 유효값 여부 |

계산 시간간격과 3D 저장 간격은 분리한다. 경계 질량은 매 시간단계 적분하고, 저장된 듬성듬성한 화면 프레임으로 재적분하지 않는다. 그래프·3D 표시는 저장한 C에서 생성하고 임의로 농도분포를 움직이지 않는다. 색 범위·단면 위치·시간·농도 기준을 그림에 표시한다. 기본 기능으로 Matplotlib의 세 직교 단면과 실제 셀 농도로 색칠한 3D 점 또는 복셀 그림을 저장한다. 농도 임계값으로 셀을 가려 표시하면 임계값도 명시한다. PyVista는 같은 결과를 대화형으로 살펴보는 선택 기능이다.

## 9. 자동 검증과 제안 통과 기준

모든 기준은 **구현 전 목표값**이다. 아직 통과한 시험은 없다. 다음 기준을 수치오차가 잘 드러나는 시험조건에서 평가한다.

| 시험 | 설정·독립 기준 | 제안 완료 조건 |
|---|---|---|
| V0 입력·단위·인덱스 | 단위 왕복변환, NO3 기준 누락, 셀 좌표·배열 왕복, 물 유량 호환성 | 잘못된 입력 거부, 알려진 좌표·값 정확 복원 |
| V1 3D 순수 확산 | q=0, 닫힌 직육면체의 양수 cosine 고유모드 해석해 | 최세분 기준 질량가중 상대 L1 오차 ≤2%, 세분화에 따른 오차 감소 |
| V2 3D 이류·분산 | x·y·z 모두 속도가 있는 Gaussian, 서로 다른 Dx·Dy·Dz | 상대 L1 ≤5%, 축별 중심오차/σ ≤2%, 축별 분산오차 ≤5% |
| V3 밀폐계 보존 | 유입·유출 없는 비균일 초기 C, q=0 | 모든 계산시각 전역 상대 질량오차 ≤10⁻⁶, 국소 잔차 보고 |
| V4 알려진 경계 공급 | 상부 일부 면의 유한 질산염 펄스·하부 개방 | 독립 계산한 ∫Q Cin dt와 입력량 일치, 잔류+유출의 상대오차 ≤10⁻⁶ |
| V5 공간·시간 수렴 | 각각 최소 3수준, 상대 오차를 분리해 평가 | 주요 출력의 최종 두 수준 차이 ≤5%, 해석해 오차 감소 확인 |
| V6 독립 모델 비교 | 같은 유동장·방정식·초기·경계조건의 OpenGeoSys | 불일치 원인 기록, 사전 지정 지표 차이 목표 ≤5% |

**공통 조건**: NaN·Inf·솔버 미수렴은 실패다. 농도 음수 허용오차는 고정 농도 스케일 Cscale에 대해 \(\epsilon_C=10^{-12}C_{scale}\)를 초기 제안으로 두고, \(C<-\epsilon_C\)는 실패로 한다. 더 작은 음수도 원본 최소값·음수 질량을 기록하며 계산 상태를 잘라 보정하지 않는다. Cscale과 절대 질량 허용오차는 실행 전에 지정·기록한다.

### V1 해석해

닫힌 영역에서 다음 식을 사용한다. 0<a<1이므로 초기 농도는 양수다.

\[
C=C_b\left[1+a\prod_{j=x,y,z}\cos(\pi x_j/L_j)
\exp\left(-\pi^2t\sum_jD_j/L_j^2\right)\right].
\]

기준값은 위 식을 셀에 대해 적분한 평균이다. 정상 배경농도가 오차를 가리지 않도록 전체 C의 오차 외에 배경을 뺀 변동 성분의 오차도 보고하며, 2% 기준은 변동 성분의 L1 크기로 정규화한 오차에 적용한다.

### V2 해석해

\[
C(\mathbf x,t)=C_p\prod_j\frac{\sigma_{j,0}}{\sqrt{\sigma_{j,0}^2+2D_jt}}
\exp\left[-\sum_j\frac{(x_j-x_{j,0}-u_jt)^2}{2(\sigma_{j,0}^2+2D_jt)}\right].
\]

일정 계수·무한 영역의 해다. 검증에서는 모든 출력시각에 중심과 각 경계의 거리가 해당 축 σ(t)의 6배 이상이 되게 하여 경계 영향·잘린 꼬리 질량을 제한하고, 잘린 해석 질량도 계산한다. 기준 농도는 erf를 이용한 셀 평균으로 구한다.

\[
E_1=\frac{\sum_i\theta_iV_i|C_i-\bar C_{exact,i}|}{\sum_i\theta_iV_i|\bar C_{exact,i}|}.
\]

중심·분산도 같은 격자의 해석 셀 평균에서 계산한 값과 비교하여 셀 중심 샘플링 오차를 분리한다. 연속 해의 중심 \(x_{j,0}+u_jt\), 분산 \(\sigma_{j,0}^2+2D_jt\), 최대농도도 함께 보고한다. 초기시각뿐 아니라 서로 다른 두 개 이상의 양의 시각에서 비교한다.

### V5 수렴성

- 공간시험은 h, h/2, h/4로 실행하되 시간오차가 충분히 작음을 먼저 확인한다.
- 시간시험은 Δt, Δt/2, Δt/4로 실행하되 같은 격자·물리조건·비교시각을 사용한다.
- 누적 유출 질량·t50·분포 오차 등을 비교한다. 거의 0인 값은 사전 지정한 질량·시간 스케일의 절대오차로 평가한다.
- 두 시험을 동시에 세분화한 결과만으로 공간오차와 시간오차가 각각 검증되었다고 표현하지 않는다. 5% 미달성 또는 비수렴이면 추가 세분화·수치법 검토가 필요하다.

### V6와 실제 정확도의 구분

우선 같은 일정 함수율·유동장 조건의 보존성 용질 수송을 비교한다. 좌표·농도 단위, θ=nSl, Darcy 플럭스, 분산·굴곡도 정의, 유입 경계 종류, 초기조건, 유출 BTC의 가중법까지 맞춘다. 각 솔버의 격자·시간오차를 먼저 확인한다. 차이가 5% 이내인 사실만으로 한쪽 결과를 참값으로 간주하지 않는다.

그 후 Padilla 예제를 재현하거나 외부 유동장을 도입할 수 있지만, 비정상 Richards 결과를 읽는 기능 자체는 현재 일정 유동 엔진의 범위를 넘는다. 이 예제의 실측 BTC와의 비교도 1차원 NaCl 수송 검증으로 표시한다. 실제 토조의 질산염 침투 정확도·매질 불균질성·우선흐름·장기 꼬리효과는 별도 실험으로 평가해야 한다.

## 10. 구현 작업 분할과 단계 진입 조건

아래는 이후 개발 순서이며, 현재 문서는 작업 A를 위한 검토안이다.

| 작업 | 구현 산출물 | 다음 작업 진입 조건 |
|---|---|---|
| A — 공통 계약 | 설정·단위·격자·상태·시험 실행 틀 | V0, 질량·좌표 규격 확인 |
| B — 확산과 보존 | 3D 확산 계산, 닫힌 경계, 기본 면 플럭스 진단 | V1·V3 및 기존 시험 통과 |
| C — 이류와 경계 | 3D 이류·분산, 일정 유동, 유입 펄스·개방 유출 | V2·V4 및 기존 시험 통과 |
| D — 분석과 수렴 | BTC·분포·CSV/NPZ/JSON·기초 시각화, 수렴성 실행 | V5·재로딩·다시 그린 후 데이터 불변 확인 |
| E — 외부 비교 | OpenGeoSys 동조건 비교와 차이 보고 | V6 평가, 불일치 해소 또는 적용한계 명시 |

B〜E마다 기존 자동시험을 다시 실행한다. 작은 회귀시험과 계산량이 큰 수렴시험을 분리하되, 해당 단계 완료 전에는 필요한 전체 검증을 실행한다. 시험이 실패하면 이후 기능을 추가해 결과를 덮지 않는다.

완료 상태는 두 가지로 보고한다. **Stage 1-A: 자체 수치검증 완료(V0〜V5)**, **Stage 1-B: 독립 모델 비교 완료(V6)**. 이후 Stage 2의 연구용 기반으로 사용하기 전에는 두 상태를 모두 검토한다. 검증을 통과하지 않은 매개변수 범위에는 검증 범위를 일반화하지 않는다.

## 11. 지금 확정할 개발 선택과 나중에 필요한 실험 정보

현재 권장하는 선택은 **FiPy 기반, 주어진 일정 θ·q, 직교 3D 격자, Upwind+후진 Euler 기준선, 설정파일·명령행 실행, 검증 후 확장**이다.

실제 토조 크기·관수 유량·토양 물성은 현재 미확정이어도 해석해 검증용 엔진을 만들 수 있다. 모든 가상 입력은 `synthetic_verification`으로 표시한다. 실제 실험을 예측하는 실행으로 전환하기 전에는 토조 내부 치수, 토양의 공극률·함수율·분산계수 근거, 관수 면적·유량·농도·시간, 하부 배수·시료채취 구조를 확보해야 한다.

반응재의 용존형·현탁형·충전형 여부는 이후 반응재 모델 선택에 필요하며, 이번 질산염 단독 수송 구현을 막는 조건으로 두지 않는다.
