1. 무엇을 분리해서 검사했나

물의 흐름·수분함량을 고정하고 반응과 주입원을 없앴다. 초기 추적자의 이동·확산만 계산해, 정답이 알려진 1차원 이류·확산식 ∂C/∂t + v∂C/∂x = D∂²C/∂x²에 대조했다. 우리 모델은 기존 3D 수송 코드의 횡방향 균일 조건(N×2×2 셀), OGS는 같은 연속 문제의 1D 선형 요소를 사용했다.

이전 3D 비교와 같은 OGS RichardsComponentTransport를 실제 실행했다. 포화도 S=1, 공극률·함수율 θ=0.3, 압력 구배 일정, 중력 0으로 고정했다. 이 경우 두 식은 동일한 상수계수 수송식으로 줄어든다. 주입 희석 λ, 흡착, 붕괴, 입자는 없다. 진단값을 실제 토양·현장 계수로 사용하지 않는다.

확산 길이 척도 √(2Dt)는 120초에서 약 1.55 mm다. N100의 셀 폭 5 mm, N200의 2.5 mm는 이보다 크다. 급격한 경계를 계산할 때 우리 모델에는 퍼짐과 형상 오차가, OGS에는 형상 오차와 비물리적 음수 농도가 나타났다. N800의 셀 폭은 0.625 mm다.

같은 초기 연속 분포를 FV는 셀 평균, FEM은 절점 값으로 표현한다. 직사각형 경계 절점은 농도의 절반 값으로 정의해 초기 총질량을 일치시켰다. 그래도 FEM의 선형 보간은 초기 경계를 유한 폭으로 표현하므로, 초기 셀 평균 L1 차이가 N100에서 12.5%, N800에서 1.5625% 존재한다. 표의 최종 오차에는 이 초기 표현·공간 이산화·시간적분의 영향이 함께 포함된다.

4. 격자만 늘리면 충분한가

급격한 경계의 N800에서 OGS 오차는 Δt 0.05초일 때 5.4778%, 0.0125초일 때 1.8536%였다. 우리 모델은 같은 변경에서 2.8489→2.8328%였다. OGS의 후진 Euler와 우리 모델의 SSPRK2가 동일한 시간 오차를 갖는다고 볼 수 없다.

  • 매끈한 분포 N100: Δt 0.05→0.025 s, 각 코드 내부 분포 변화 우리 0.0003%, OGS 0.2223%.
  • 급격한 경계 N800: Δt 0.05→0.0125 s, 각 코드 내부 분포 변화 우리 0.0176%, OGS 3.6257%.

시간간격 축소로 OGS 분포 오차는 줄었지만 음수 최저값은 0에 더 가까워지지 않았다. 정확도와 비음수성을 각각 확인해야 한다. N800·Δt 0.0125초의 저장 시각 중 최저값은 30초의 -0.2070522 mg/L이고, 최종 120초에서는 -0.0037373 mg/L다. 농도를 잘라 지우거나 총량을 재정규화하지 않았다.

6. 질량·단위·오차의 정의

표의 오차는 공통 셀 평균에서 ΣΔx|C계산−C해석| / ΣΔx|C해석|로 계산했다. 두 코드 차이도 같은 해석해 질량으로 정규화했다. θ가 일정하므로 θC 질량장 상대 오차와 같다. 이전 3D 보고서는 자작 질량장을 분모로 썼으므로 수치를 직접 같은 지표로 혼용하지 않는다. OGS 절점 농도는 선형 요소 내부에서 정확히 평균했고, 최저값은 원본 절점에서 평가했다.

초기 총질량은 가우시안 약 0.060159 mg, 직사각형 약 0.048000 mg다. 실제 물 주입은 없으며, 이전 0.6 mg 주입 사례와 다르다. 우리 모델의 최대 질량수지 상대 잔차는 1.09e-13. OGS의 최대 영역 내 총질량 변화는 초기량의 0.011686%다. OGS 값은 경계 플럭스 장부를 재구성한 수지 잔차가 아니라 영역 총질량 변화다.

무한 영역 해석해와 수치 경계 C=0의 차이를 1001개 시각에서 평가했다. 최대 경계 농도 2.44e-14 kg/m³, 초기 농도 크기 대비 6.1e-13였다. 이를 무한 영역과 유한 영역의 수학적으로 완전히 동일한 경계조건이라고 부르지 않는다.

7. 실행·재현 증거

완료된 OGS 실행 9개, 각 5개 시각의 원본 VTU/PVD, 원본 로그·종료코드·입력 해시, 자작 배열·질량수지, 정확해 배열·비교 CSV를 보존했다. 원본 Python 45개는 이전 저장본과 동일하다. 기존 자동시험 57개 통과, 별도 해석해 검산 65개 통과. 해석해는 Green 함수 적분 및 독립 수치적분으로 검산했다.

5%·1%와 음수 판정 크기는 내부 진단 기준이며 외부 인증이나 실험 정확도 기준이 아니다. 음수 판정은 저장된 시각에 한정한다. 실행 중 모든 시간의 최소값을 기록했다고 주장하지 않는다. 이번 결과는 수치검증이며 실제 토양·실험 검증과 구분한다.
