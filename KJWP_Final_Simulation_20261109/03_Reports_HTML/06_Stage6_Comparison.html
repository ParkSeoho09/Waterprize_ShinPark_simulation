Stage 6 · 배치별 정량 성능 비교

빠른 모드 구현과 48시간 비교

대표 주입 5개와 무주입 대조군을 동일 입력으로 재계산했다. 주입 5개 케이스의 기록된 계산 시간 합계 기준으로 빠른 모드가 19.7배 빨랐다. 시간은 서로 다른 실행에서 기록된 케이스별 시간의 합이며, 배치 전체의 실제 대기시간과는 별도다.

반응량 최대 절대 편차는 3.32 mg이다. 정밀 모델과 빠른 모델의 반응량 상위 2개가 2/2개 겹쳤고, 무주입 대비 바닥 유출 변화의 방향은 5/5개에서 일치했다. 상위 2개 중첩은 대표군 검증 지표로 사용했다. 최종 배치 선정은 스테이지 7 이후로 둔다.

15×15×25 격자와 시간 간격은 두 실행에서 같았다. 빠른 모드는 초기 pH에 따른 억제 인자를 고정하고 Monod 반응을 후진 오일러로 적분한다. PHREEQC는 초기 용액 조성에 사용한다. 방해석 용해와 pH 변화를 생략하며, 황산염은 황 반응의 화학양론으로 계산한다.

6개 쌍 모두 입력, 투입량, 질산염·성분·물 수지 검사를 통과했다. 이 비교는 저장된 정밀 모델과의 일치도를 평가한다. 대표군 밖에서의 순위 재현성과 실험 검증은 후속 과제다.

모의시간 48시간. 평가 검사 통과: True. 실제 현장/실험 성능이 아닌 시나리오 계산이다.

기준 설정에서 누적 질산염 반응량이 가장 큰 후보는 B00035(976.526 mg, 초기량+유입량 대비 3.216%)다. 현재는 1차 비교이며 수치 민감도 결과가 연결되기 전에는 배치 우열을 확정하지 않는다.

수치 민감도와 순위 판단

민감도 결과가 아직 연결되지 않았다. 현재 순위는 1차 선별용이며 최적 배치로 확정하지 않는다.

검증 및 남은 범위

• 공통 조건 일치: True; 동일 실제 고체/운반수/성분 투입: True.

• 원본 입력 해시, 완료 시각, CSV/요약 일치, 모든 기록 시각의 성분 수지·물 수지, 희석/반응 분리 장부, 황산염 화학양론을 검사했다.

• 수지 통과 기준: 성분 10⁻¹⁰ kg + 상대 10⁻⁸, 물 10⁻⁹ m³ + 상대 10⁻⁸. 수치 민감도와 질량수지 통과는 서로 다른 조건이다.

• 선택한 5개 후보만 비교했다. 23,223개 전체 검색, 깊이 최적화, 실측 반응속도/입경/토양 보정, 관 내부 손실, 독립 소프트웨어/실험 검증은 미완료다.

• 산소 수송·생물량 성장·막힘·관벽 배제 부피는 기존 엔진의 미구현 범위다. Stage 7 UI 완료를 뜻하지 않는다.

python evaluate_stage6.py stage6_runs/primary --out stage6_results/primary
