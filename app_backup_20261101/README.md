# SLAD 반응재 배치 방식 비교 시뮬레이터 (v2)

농경지 불포화대 질산염이 지하수로 내려가는 것을 막는 **황:CaCO₃(3:1 v/v) SLAD 반응재**의
**배치 방식**(케이슨형, 영구 주입공, 케이싱 접근형 등)을 흙수조에서 비교하는 범용 시뮬레이터입니다.

비교군은 코드에 고정돼 있지 않습니다. 각 비교군은 다음으로 넣습니다.

1. **3MF 파일**: 객체마다 역할 지정
2. **작용 메커니즘 설명**
3. **설치(꽂는) 방법 표**: 삽입, 개구부 열기, 시약 주입, 정치, 재보충…

어떤 입력이 와도 같은 물리로 계산합니다.
평가지표 6개는 「흙수조 비교실험 측정 지표 체계」 문서 정의를 따릅니다.

---

## 실행

1. `run_app.bat` 더블클릭
   - 처음에는 패키지를 설치하느라 몇 분 걸립니다.
2. 브라우저에서 `http://localhost:8501` 이 열립니다.
3. **① 비교군 입력** → **예시 불러오기**(영구 주입공, 케이슨형)로 바로 해 볼 수 있습니다.
4. **③ 실행** → **④ 결과·애니메이션**
   - 비교군이 없어도 ④ 탭에서 **기본 대조군(꽂지 않았을 때)** 그래프와 애니메이션이 열립니다.

수동 실행:

```
cd 이 폴더
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Streamlit 없이 계산만 하려면:

```
python run_cli.py slad_project.json
python run_cli.py --examples --days 120
```

검증 다시 실행:

```
python verify/run_verification.py --quick
```

(약 40분. 두 창에서 `--part=main`과 `--part=V5`로 나눠 돌리면 더 빠릅니다. `--part=main`을 V5 다음에 끝내면 V5 결과가 자동으로 합쳐집니다.)

## 이번 판에서 바뀐 점 (기존 앱 점검 결과 대응)

| 점검 결과 | 기존 | 이번 판 |
|---|---|---|
| 1. 흐름이 Richards가 아님 | `v = q/θ` 균일 하강. Soil의 α, n, Ks 미사용 | **3D Richards(van Genuchten–Mualem) 실제 해석.**<br>셀 중심 유한체적, 조화평균 K, 뉴턴(정상), 수정 Picard(과도), scipy.sparse.<br>상단 플럭스(포화 시 h=0 전환), 하단 지하수 수위 또는 자유배수, 측면 무유동(지하수 유속을 주면 지하수층에 고정 수두 기울기) |
| 2. 투수성 피드백 끊김 | `k_rel` 계산만 함 | 공극률(황·석회석·석고·생물막·주입 고형분) → Kozeny–Carman → **흐름 재계산 → 수송에 되먹임**.<br>K가 5% 넘게 변하거나 정해진 주기가 되면 재계산 |
| 3. 재보충이 모든 구조에서 동일 | 180일마다 일괄 복원 | **설치 단계 표가 규칙을 정함**. 개구부 주입 또는 카트리지 교체.<br>개구부·교체 가능 객체가 없으면 재보충 불가 → **R=0** (사용자가 '개구부 없이 재보충 허용' 체크 시 예외).<br>T_r는 구조별 표 값 |
| 4. 3MF 처리 오류 | 객체를 합쳐 짝홀 판정, m로 가정하고 90% 자동 축소, 빈 마스크면 원기둥으로 몰래 대체 | **object 단위로 읽음**(이름, `unit` 속성, build item·component 변환).<br>단위 mm/cm/m 선택, **자동 축소 없음**.<br>객체별 복셀화, 닫힌 메시 검사, 두께 추정.<br>얇은 벽은 **셀 사이 면 장벽**으로 넣음.<br>반응재·개구부 복셀이 0이면 **오류로 멈춤**(샘플로 대체하지 않음) |
| 5. 석회석 즉시 평형 | 평형만 | **PWP 속도식(기본)** 또는 평형 선택. pH는 알칼리도·pCO₂·Davies 활동도에서 전하 균형으로 계산 |

추가로 구현한 것:

- **설치 과정 재현**: 구조물 삽입 시점에 흙에 들어감. 인발, 개구부 열기·닫기.
- **슬러리 주입 물리**: 주입 압력 흐름(중첩 근사), 입자 이송 + 여과 포획(차단 함수). 포획된 입자가 반응재가 되고, 쌓이면 개구부 주변이 막힘.
- **텍스트 → 설치 단계 표 변환**: 규칙 기반. Anthropic API 키가 있으면 LLM 변환도 선택 가능.
- **지하수층과 '지하수 피해' 보조지표**
- **기본 대조군 자동 계산**: 모든 실행에서 같은 조건, 같은 격자로 계산.
- **애니메이션**: 설치 과정, 결과 3D 레이어, 다중 비교. 카메라·시간 동기화, 단면 자르기, 파라미터 표시.
- **입력 제한 없음**: 모든 숫자 입력에 최솟값·최댓값이 없음. 비현실 값은 노란 경고, 계산이 불가능한 값은 해당 실행만 막음.
- **Excel 내보내기**: 8개 시트, 네이티브 차트.
- **기타 저장**: npz/json, CSV, PNG, 애니메이션 HTML.

## 물리 요약

수식은 앱 ⑤ 탭의 '계산 방법 보기'에 있습니다.

- **흐름**: Richards 방정식, van Genuchten–Mualem 흙 성질(Carsel & Parrish 1988 토성 평균값). 운영 중 흐름은 기본이 **준정상**입니다. 정상해를 정해진 주기마다, 또는 투수성이 5% 넘게 바뀌면 다시 풉니다. 이 점은 UI에 표시되며, '과도' 모드도 고를 수 있습니다.
- **수송**: NO₃, SO₄, Ca, 알칼리도, 주입 입자. TVD(van Leer) 2차 이류, 종·횡 분산과 Millington–Quirk 확산. 안정 조건에 맞춰 Δt를 자동으로 나눕니다.
- **반응**: SLAD 양론은 Batchelor & Lawrence(1978)입니다. NO₃⁻ 1 mol당 SO₄²⁻ 1.10 mol, 산 1.28 eq이 생깁니다. 이는 NO₃-N 1 mg당 SO₄ 7.54 mg, 알칼리도 4.57 mg as CaCO₃에 해당하며, 지표 문서 값과 일치하는지 V3에서 확인했습니다. 속도는 반-차수(k = 5.0 mg^½L^-½h^-1, 보고 범위 4.36~6.91의 중간값)에 황량·pH·온도 보정을 곱합니다. 석회석은 PWP 속도식 또는 평형, 석고는 평형 침전, 생물막 성장·감쇠는 가정입니다.
- **설치·주입**:
  - 주입 중 흐름은 현재 흐름장에 포화 다르시 압력 섭동장을 더합니다(**가정: 중첩 근사**).
  - 입자는 λ|v|·B(φ)로 포획됩니다. B는 남은 공극 비율이고, λ와 최소 공극률은 가정입니다.
  - 관개 전 설치 단계의 배경 흐름은 정지 상태로 봅니다(가정).
- **지표 유출 재분배**(기본 켬, 가정): 구조물 덮개 위나 포화 지표에서 못 들어간 물은 열린 흙 표면으로 들어갑니다.

> **'작업 지시서 요구 1.25'에 대하여**: 지시서에는 "NO₃⁻ 1 mol당 SO₄ 1.25 mol"이라고 적혀 있습니다. 그런데 같은 지시서와 지표 문서의 이론값(NO₃-N 1 mg당 SO₄ 7.54 mg)에 해당하는 비는 **1.10**입니다. 1.25로 하면 8.58 mg이 됩니다. 그래서 문서 이론값과 맞는 Batchelor & Lawrence 양론(1.10)을 기본으로 썼습니다. 값은 ② 탭 '고급 파라미터'에서 바꿀 수 있습니다.

## 평가지표

정의는 지표 문서 그대로입니다. 계산 방법은 ⑤ 탭에 있습니다.

1. **질산염 제거효율 η, Q_N**
   - 평가 구간은 대조군 유출이 유입의 90%에 도달한 날 이후입니다. 그 전에는 '도달 지연' 때문에 반응재가 없어도 η가 높게 나오는 착시가 생깁니다.
   - **대조군 보정 제거율**을 함께 표시합니다.
   - 재보충 전·후 구간은 나눠 계산합니다.
2. **ΔpH**: 반응재 주변부, 반응재 아래 0~10 cm, 바닥 유출부의 시간 변화와 깊이 프로파일. 기준은 초기 토양 pH(입력값)입니다.
3. **r, V_eff**: r은 공급 지점(주입 개구부, 또는 사전 배치 반응재)에서 반응재까지의 최대 수평거리입니다. V_eff는 흙수조 안에서 |ΔpH|<0.5이면서 SO₄가 증가한 셀의 부피입니다.
4. **투수성**: 흐름 계산에서 직접 냅니다.
   - 도메인 유효 K: 토양층 정수두 시험을 계산으로 재현
   - 반응재 영역 K: 조화평균
   - 유지율은 운영 시작 대비 %, 재보충 때마다의 값도 기록합니다.
5. **재보충 성능 회복 R, N_max, T_r**: 24시간 후 값(문서 방식)과 '반응재→유출부 이동시간 보정' 값을 모두 계산합니다. 흙수조에서는 바닥까지 며칠이 걸리기 때문입니다.
6. **유출수 SO₄, 이론비**: 실제 제거량(대조군 유출 − 비교군 유출) × 7.54와 비교합니다.

- **보조지표**: 지하수 도달 NO₃-N 누적, 대조군 대비 감소율, 10 mg/L 도달일

## 예시 3MF 두 개로 알게 된 점

- **케이슨형(caisson_gate)**: 외피와 내부 챔버 벽이 얇은 강판(0.5 mm)이고 바닥판(outer_floor)이 막혀 있어, 수직으로 스며드는 물이 반응재를 통과할 길이 없습니다. 시뮬레이션에서 반응재를 지나는 물이 0(진단값 '반응재 통과 유량/투영면 강수' = 0)으로 나와, 제거효율이 대조군과 같습니다.
  - 실제 흙수조에서 케이슨 바닥이 열려 있거나 유입·유출구가 있다면, 역할표에서 `outer_floor`를 '투수 충전재'나 '토양'으로 바꾸거나 유입구 객체를 추가하세요.
  - 이 결과는 3MF 형상을 그대로 해석한 것입니다.
- **영구 주입공(injection_well)**: 2.84 L(고형분 20%) 주입으로 케이슨과 같은 반응재 질량(약 1.27 kg)을 만들었습니다. 반응재는 스크린 주변 수 cm에 형성되고, 재보충을 반복하면 스크린 주변 공극이 차서 반응재 영역 K가 떨어집니다. 이는 지표 문서의 '주입관 막힘 누적' 가설과 같은 방향입니다.

## 알려진 한계 (앱 결과 화면에도 항상 표시)

- 운영 중 흐름은 준정상 근사가 기본입니다. 하루 단위 강우 변동은 없습니다.
- 주입 중 압력 흐름은 포화 다르시 중첩으로 근사합니다. 마른 흙이 젖어 가는 지연과, 흙을 밀어내는 할렬 주입은 없습니다.
- 격자보다 가는 관·스크린은 칸 전체로, 얇은 벽은 면 장벽으로 표현합니다. 관 내부 단락 흐름은 없습니다.
- 다음은 모델에 없습니다: 종속영양 탈질, 암모늄, 양이온 교환, 토양 자체 완충, 온도에 따른 평형상수 변화.
- 탈질 속도상수는 문헌 범위 중간값이며 이 실험으로 보정하지 않았습니다(V3c 미검증).
- 막힘 관련 계수는 가정입니다: Kozeny–Carman, 생물막 부피 계수, 포획 계수 λ.
- 계산 시간(2코어 기준 실측):
  - 가벼움 격자: 대조군 1년 약 1분
  - 보통 격자: 약 4분
  - 비교군은 반응·주입 때문에 더 걸립니다.
